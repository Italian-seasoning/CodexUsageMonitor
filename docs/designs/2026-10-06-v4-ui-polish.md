# Version 4 UI polish

Version 4 uses the smaller workspace with animated sides. The workspace opens at 480 × 500 and keeps its existing architecture. The larger analysis window is removed from app actions and menus.

## Changes

- Shared page headers use the same title and caption scale, retain their subtitles at narrow widths, and use small native controls. Card titles wrap their subtitles when an inline layout does not fit.
- Model comparisons show a name and percentage above each native progress bar, with accessible descriptions. The Models icon is a CPU symbol. The repeated oversized model headline is removed.
- Trends bars resize with the available chart width using Swift Charts [relative mark dimensions](https://developer.apple.com/documentation/charts/markdimension/ratio(_:)). A single bar stays 48 points wide. Date labels align with their bars; lifetime bars use the same weekly interval as the aggregated data.
- The shared Details button has a visible label, a larger target, and an Option–Down shortcut. Native scrolling and `ScrollViewReader` replace snap behavior that prevented jumps to the taller Trends details section.
- Sessions uses the shared header, clearer row values, and disclosure arrows. The chat selector has one chevron.
- Navigation appears as the pointer enters the left edge. Mouse movement animates the elastic side and reveals the rail without a press or drag. The tracker passes clicks through and leaves the cursor alone. Clicking an icon selects a page; hovering only highlights it. Escape dismisses the rail, and leaving it closes it after a short delay.
- The upper page selector is removed. Page navigation lives in the side rail, with keyboard shortcuts retained.
- Window controls have larger hit areas. Window dragging is limited to the empty space in the top bar. The green control zooms the compact window. Menu-bar workspace actions open the compact workspace.
- A dark backing preserves the native desktop blur while making text legible. Cards use subtle fills and borders instead of stacked glass effects. Native controls use the dark appearance.
- Rain uses fewer thin streaks without bright snow-like dots. Autumn uses four small, slowly drifting leaves and no rain. Both animations stay within narrow outer margins, clear of text and charts, and respect reduced motion.
- Activity removes the repeated brand heading, theme shortcut, chart caption, and event count. The theme control lives in Settings. Reasoning metadata and recorded event counts live under Details.
- Settings combines monitoring and its collapsed notifications controls. Version and build metadata move into Setup and updates.
- Workspace commands appear in the Window menu, eliminating the duplicate View menu.
- The native event test covers pointer-only reveal, click and drag pass-through, accessibility activation, and Escape dismissal/pass-through.
- Settings labels the appearance picker “App theme.”
- Activity uses a compact chat heading, model/context row, one dominant token total, a secondary request count, and a 48-point session sparkline. Cached share moves into Details. The health and refresh controls align above Details.
- Allowance uses paired 5-hour and weekly dials, shared by the compact app and Limits widgets. Reset labels wrap without reducing their font size; expired windows show unavailable data.
- Widget metrics share a 14-point inset and columns aligned to their leading edges. Long labels wrap into two lines. Small widgets use one secondary metric on a single row.
- Widget chart forms match their data: allowance and model share use dials, session history uses a line, daily totals use bars, and Headroom savings uses dots. Small Model Mix uses daily bars rather than a native progress control unsupported by the renderer.
- Widget size controls use one compact row and segmented picker. The large preview retains its natural height instead of being squeezed into a 200-point frame.
- `scripts/RenderWidgetGallery.swift` renders the actual shared widget views using a supplied snapshot, producing a gallery and individual PNGs for all seven families in all three sizes.
