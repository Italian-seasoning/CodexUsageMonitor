Privacy policy

Your Codex data stays local.

Data access

Codex Usage Monitor reads local Codex session logs and, when installed, the local Headroom database. macOS asks for permission before the app reads another app’s protected data.

Data collection

The app does not collect, transmit, sell, or share prompts, responses, token usage, model history, session history, or Headroom statistics. It does not include analytics or advertising SDKs.

Storage

Usage snapshots and widget settings are stored locally in Application Support. Removing the app and its local support data removes this cached history.

Network access

Sparkle connects to GitHub Releases to check for app updates. Update archives are verified with an EdDSA signature before installation. No Codex usage data is included in update requests.

Contact

Questions and issues can be filed in the project’s GitHub issue tracker.
