Privacy policy

Your session history stays local.

Data access

Codex Usage Monitor reads local Codex session logs and, when installed, the local Headroom database. macOS asks for permission before the app reads another app’s protected data. If ChatGPT desktop or the Codex CLI is installed, the monitor also requests account lifetime totals and current limits through Codex's app-server.

Data collection

The app does not upload, sell, or share prompts, responses, local session history, model history, or Headroom statistics. It does not include analytics or advertising SDKs.

Storage

Usage snapshots and widget settings are stored locally in Application Support. Removing the app and its local support data removes this cached history.

Network access

Codex's app-server may contact OpenAI using your existing sign-in to return account usage and limits. The monitor does not send local session logs or Headroom data through that request. Sparkle connects to GitHub Releases to check for app updates. Update archives are verified with an EdDSA signature before installation. No Codex usage data is included in update requests.

Contact

Questions and issues can be filed in the project’s GitHub issue tracker.
